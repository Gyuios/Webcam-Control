# CameraTuner 0.1.0 alpha 1

Primera versión pública de prueba de CameraTuner.

## Incluye

- Captura nativa de webcams y selección de resolución, FPS y formato.
- Controles físicos expuestos por el driver y acceso al panel del fabricante.
- Vista previa optimizada con recuperación ante bloqueos.
- Grafo ordenado de filtros de software, LUT 3D y corrección de lente.
- Perfiles separados por dispositivo.
- Cámara virtual Media Foundation para Discord, Zoom y otras aplicaciones.
- Reescalado bilinear y Lanczos3.
- Plugins declarativos y registros estructurados de diagnóstico.

## Instalación

1. Descarga `CameraTuner_0.1.0_x64-setup.exe`.
2. Ejecuta el instalador y acepta la elevación de administrador.
3. Abre CameraTuner, selecciona la cámara y activa la salida virtual.
4. Selecciona **CameraTuner Virtual Camera** en la aplicación de videollamada.

## Avisos de esta versión temprana

- Requiere Windows 11 x64, build 22000 o posterior.
- El instalador aún no tiene firma comercial y Windows SmartScreen puede mostrar una advertencia.
- El reescalado con IA todavía no está incluido; las opciones disponibles son algoritmos clásicos.
- Algunas cámaras anuncian modos que su propio firmware no inicia correctamente. Si ocurre, prueba otro formato o resolución.

Los problemas pueden reportarse en [GitHub Issues](https://github.com/Gyuios/Webcam-Control/issues) adjuntando los registros de diagnóstico, pero nunca imágenes privadas de la cámara.
